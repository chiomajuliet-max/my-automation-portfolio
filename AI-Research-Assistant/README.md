# AI Research Assistant

## Project Overview
An AI-powered research assistant built with n8n, Telegram and Tavily Search.

This automation allows users to ask questions through Telegram and receive answers based on information retrieved from the internet.

## Tools Used
- n8n
- Telegram Bot
- Tavily Search API
- AI Automation

## How It Works
1. A user sends a question through Telegram.
2. The Telegram Trigger receives the message.
3. Tavily Search retrieves relevant information from the internet.
4. The workflow processes the search results.
5. The bot sends the response back to the user on Telegram.

## Project Purpose
To demonstrate how AI and workflow automation can make internet research faster and easier.
